Omid QUANT — بسته آماده انتشار وب

این بسته یک وب‌اپلیکیشن ایستا (Static Website) است. برای داشتن لینک عمومی باید آن را روی سرویس میزبانی منتشر کنید؛ این فایل به‌تنهایی هنوز روی اینترنت منتشر نشده است.

روش پیشنهادی: GitHub Pages
1) در GitHub حساب بسازید یا وارد حساب خود شوید.
2) یک repository جدید بسازید و آن را Public قرار دهید؛ مثلاً omid-quant.
3) فایل index.html همین بسته را در ریشهٔ repository بارگذاری کنید و Commit changes را بزنید.
4) در repository به Settings → Pages بروید.
5) در بخش Build and deployment، گزینه Deploy from a branch را انتخاب کنید.
6) Branch را روی main و folder را روی /(root) قرار دهید و Save را بزنید.
7) پس از چند دقیقه، GitHub یک آدرس شبیه https://USERNAME.github.io/omid-quant/ می‌دهد.

- این نسخه برای خواندن فایل‌های Excel به اتصال اینترنت نیاز دارد، چون کتابخانه‌ها از CDN بارگیری می‌شوند.
- قبل از استفاده واقعی، فایل‌های مالی را با گزارش اصلی تطبیق دهید؛ تشخیص خودکار ستون‌ها ممکن است نیاز به اصلاح دستی داشته باشد.
- این نسخه تحلیلگر آموزشی/آزمایشی است، دادهٔ زنده بازار دریافت نمی‌کند و توصیهٔ قطعی خریدوفروش نیست.
- برای بارگذاری عمومی واقعی، لازم نیست فایل‌های مالی کاربران به سرور ارسال شوند؛ این نسخه در مرورگر کاربر پردازش می‌کند.
